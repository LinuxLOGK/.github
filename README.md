# .github

LinuxLOGK 조직의 공통 설정 저장소입니다. 여기 있는 이슈·PR 템플릿은 자체 템플릿이 없는 조직 내 모든 저장소에 기본값으로 적용됩니다.

| 파일 | 용도 |
| --- | --- |
| `.github/ISSUE_TEMPLATE/bug_report.md` | 버그·회귀 보고 |
| `.github/ISSUE_TEMPLATE/task.md` | 작업 등록 |
| `.github/ISSUE_TEMPLATE/decision_request.md` | 결정 요청 |
| `.github/PULL_REQUEST_TEMPLATE.md` | PR 본문 |

템플릿을 고치려면 이 저장소의 `main` 브랜치에 반영합니다.
